# Kie: Crafted Elegance

ПРОМПТ ДЛЯ LOVABLE

Ты создаёшь сайт для ювелирного дома kie (пишется строчными в логотипе) — премиального, но современного e-commerce бренда украшений ручной работы.

О бренде
Название: kie
Основатель/дизайнер: Nurgul Utep (Нургуль Утеп)
Локация: ателье в Астане, Казахстан, с 2026 года
Instagram: @kie.kz (реальный аккаунт)
Слоган: «Единичные экземпляры. Единственные в своём роде.»
Позиционирование: небольшие партии, а не массовая витрина; форма важнее орнамента, качество металла важнее количества камней. Один и тот же мастер ведёт модель от эскиза до полировки.
Тон голоса: сдержанный, уверенный, без маркетинговых восклицаний и без скидочной риторики («−25%», «горячие предложения» — это чужой тон, не наш). Премиальный бутик, а не маркетплейс.
Валюта и рынок
Казахстан, тенге (₸). Цены указываются с разбивкой по тысячам через пробел, например 237 600 ₸.

Дизайн-система
Флэт-модернизм: минимум декора, чёткая сетка, тонкие горизонтальные разделители между секциями (1px, не толще), нулевые скругления углов везде.

Цвета:

Фон: #f3f2f2
Поверхность/плашки: #eae9e9
Текст (почти чёрный): #201e1d
Акцент (красный, только для hover и цен): #ec3013, тёмный вариант для цен: #ae1800
Второстепенный текст: #7d7979
Разделители: #201e1d на 40% прозрачности
Шрифты:

Основной текст и заголовки (кириллица): Golos Text (Google Fonts)
Логотип и латинские названия коллекций (например «kie», «Nur», «Dala»): Archivo — используется только для латиницы, у него нет поддержки кириллицы
Фото: все карточки товаров — квадратные (1:1), студийные фото на белом/светлом фоне, object-contain, без обрезки важных деталей украшения.

Структура главной страницы (сверху вниз)
Header — двухстрочный, компактный. Первая строка: слева «Est. 2026», по центру логотип «kie», справа иконки (поиск, профиль, избранное, корзина). Вторая строка: категории каталога по центру на десктопе (на мобильном — горизонтальный скролл, начинается с первого пункта, не обрезан).
Промо-слайдер (Hero) — баннер с ротацией 1–2 «спотлайтов» коллекций, точки-навигация внизу (кликабельные). Слева: название коллекции крупно (Archivo) → «Новая коллекция» → короткая цитата бренда → мелкая приписка → ссылка «Смотреть коллекцию». Справа: квадратное фото товара. Никаких выдуманных скидок/дат распродаж.
Бегущая строка брендов — медленная бесконечная анимация (≈60 сек на цикл), некрупный текст. Показывает реальных поставщиков каталога (Roberto Bravo, Leonardo) вперемешку с мировыми ювелирными домами для атмосферы (Cartier, Tiffany & Co., Van Cleef & Arpels, Bvlgari, Chopard, Pandora, Swarovski) — с подписью сверху «Ювелирный мир», чтобы не читалось как заявление о партнёрстве.
Бестселлеры — горизонтальная карусель со стрелками, 4 карточки: фото 1:1 на белом фоне без рамки-подложки, под фото — название, материал/вес, цена (акцентным цветом). Заголовок секции — обычным начертанием, капслоком.
Популярные коллекции — 3 компактные квадратные карточки-баннера (фото + градиент-оверлей снизу + название крупно + короткое описание + ссылка).
Мир kie / лукбук — асимметричная фотосетка: атмосферные фото украшений + одна текстовая плашка о технике исполнения (например «Ручная роспись эмалью по металлу»).
О доме — текст (2 коротких абзаца) + фото, без выдуманных дат основания, имён или конкретных фактов, которых нет.
На человеке — lifestyle-галерея (украшение на ухе/руке), плюс пара крупных детальных фото товаров.
Все категории — простой список ссылок на реальные категории каталога.
Подписка на новости — email-инпут + кнопка, без ложных обещаний скидок.
Footer — тёмный фон (#201e1d), логотип «kie» крупно, блоки «О доме» / «Клиентам» / «Контакты», иконка Instagram, копирайт снизу.
Реальные данные каталога
У бренда есть экспорт реального POS-каталога (~3000 товаров). Категории: Кольца, Серьги, Колье, Браслеты, Подвески, Цепи, Броши, Часы. Ориентировочные медианные цены (тенге):

Золотое кольцо: ~430 000
Бриллиантовое кольцо: ~1 100 000
Золотые серьги: ~700 000
Золотой браслет: ~1 000 000
Серебряные украшения: 80 000–110 000
Реальные сторонние линии в каталоге (не собственный дизайн kie): Roberto Bravo, Leonardo.

Важные правила честности контента
Никогда не выдумывай скидки, даты распродаж, номера телефонов или email — если реальных данных нет, оставляй только то, что подтверждено (сейчас это только Instagram).
Названия коллекций и часть товаров могут быть плейсхолдерами (временными) — это нормально, но отмечай это в комментариях к коду, а не выдавай за окончательный факт.
Не заявляй партнёрство с мировыми брендами, которых бренд реально не продаёт — если показываешь их логотипы/названия, явно подписывай это как атмосферный контекст, а не как список продаваемых брендов.
Не добавляй функциональность, которой нет (уведомления, мобильное приложение, программы лояльности), если её не попросили реализовать по-настоящему.
Технологии
Frontend: Vite + React 19 + TypeScript + Tailwind CSS v4
Backend: Go (chi router) — существует отдельно, ещё не подключён к фронтенду через API
Роутинг между страницами каталога/товара/коллекций пока не подключён — ссылки на /catalog, /collections/... и т.п. можно оставлять как понятные заглушки, если полноценный роутинг не входит в задачу.
Если нужно — могу адаптировать этот промпт под конкретную задачу (например, только для генерации страницы каталога товара или карточки коллекции), просто скажи, что именно предстоит собрать в Lovable.
